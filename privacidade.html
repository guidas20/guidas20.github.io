Política de Privacidade

Atualizada em 14/11/2026

O app-cortes é uma ferramenta de uso pessoal e interno, operada por um único criador, para enviar vídeos ao próprio canal do YouTube e à própria conta do TikTok.

Uso dos Serviços de API do YouTube

Este app usa os Serviços de API do YouTube (YouTube API Services). Ao usar o app você concorda com os Termos de Serviço do YouTube. O uso dos dados também está sujeito à Política de Privacidade do Google.

Dados acessados, usados e armazenados

O app acessa apenas o canal do YouTube do próprio autor, para: (1) enviar vídeos (videos.insert) e (2) confirmar qual canal está conectado (channels.list). Ficam guardados somente o token de acesso OAuth e o ID dos vídeos enviados, no servidor privado do autor, com acesso restrito.

Compartilhamento

Nenhum dado é compartilhado, vendido ou transferido a terceiros. Nenhum dado de outros usuários ou canais é coletado.

Cookies

O app não usa cookies, rastreamento nem publicidade, e não armazena informações nos dispositivos de usuários.

Revogação e exclusão de dados

O acesso pode ser revogado a qualquer momento na página de configurações de segurança do Google (myaccount.google.com/permissions). Ao revogar, o token deixa de funcionar e é apagado do servidor em até 7 dias. Pedidos de exclusão de dados: gtaviicity@gmail.com, atendidos em até 7 dias.

Serviços de API do Google

O uso de informações recebidas das APIs do Google segue a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado.

Privacy Policy (English)

app-cortes is a personal tool used by a single creator to upload videos to their own YouTube channel and TikTok account. This app uses YouTube API Services (YouTube Data API) and TikTok Content Posting API only to upload videos and check upload status. Access tokens are stored only on the author's private server and are never shared or sold. By using it you agree to the YouTube Terms of Service (https://www.youtube.com/t/terms); see also the Google Privacy Policy (https://www.google.com/policies/privacy). No data from other users is collected or shared; no cookies, tracking or ads. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Revoke access at https://security.google.com/settings/security/permissions; tokens are deleted within 7 days of revocation or on request. Contact: gtaviicity@gmail.com
