Política de Privacidade

Atualizada em 14/11/2026

O app-cortes é uma ferramenta de uso pessoal, operada por um único criador, para enviar vídeos ao próprio canal do YouTube e à própria conta do TikTok.

Dados acessados

O app usa a API do YouTube e a API do TikTok apenas para enviar vídeos e ler o status do envio na conta do próprio autor. Os tokens de acesso ficam guardados somente no servidor privado do autor e nunca são compartilhados, vendidos ou usados para outra finalidade.

Nenhum dado de outros usuários é coletado. O app não usa cookies, rastreamento ou publicidade.

Serviços do Google

O uso de dados recebidos das APIs do Google segue a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de uso limitado. Ao usar o app você também está sujeito aos Termos de Serviço do YouTube e à Política de Privacidade do Google.

Revogar acesso

O acesso pode ser revogado a qualquer momento em myaccount.google.com/permissions e nas configurações de apps autorizados do TikTok. Para pedir exclusão de dados, escreva para gtaviicity@gmail.com.

Privacy Policy (English)

app-cortes is a personal tool used by a single creator to upload videos to their own YouTube channel and TikTok account. It uses the YouTube Data API and TikTok Content Posting API only to upload videos and check upload status. Access tokens are stored only on the author's private server and are never shared or sold. No data from other users is collected; no cookies, tracking or ads. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Revoke access at myaccount.google.com/permissions. Contact: gtaviicity@gmail.com
